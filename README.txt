HEIGHTCOMPARE — CLOUDFLARE PAGES STARTER
=======================================

WHAT'S INCLUDED
- index.html: main height comparison tool
- styles.css: responsive styling
- app.js: calculations, person controls, visual preview and PNG export
- about.html, privacy.html, contact.html: starter information pages
- robots.txt, sitemap.xml: basic crawl discovery files

BEFORE LAUNCH
1. Replace every occurrence of https://YOUR-SITE.pages.dev with your actual Cloudflare Pages URL.
   You can use Find/Replace in a text editor.
2. In contact.html, replace REPLACE-WITH-YOUR-EMAIL@example.com with an email address you control.
3. Review privacy.html and make sure it accurately describes your real setup.
4. Test the site on phone and desktop.

FREE DEPLOYMENT: CLOUDFLARE PAGES DIRECT UPLOAD
1. Extract this ZIP on your computer.
2. Open https://dash.cloudflare.com/ and sign in or create a free account.
3. Find Workers & Pages (menu wording can change).
4. Choose Create application / Create project, then Pages if that option is available.
5. Choose the option to upload static assets directly (may be called Direct Upload or Upload assets).
6. Give the project a name such as heightcompare-tool.
7. Upload the CONTENTS of this folder, not the ZIP file itself. index.html should be at the root, not inside an extra nested folder.
8. Deploy. Cloudflare will provide a *.pages.dev URL.
9. Open that URL and test the tool.
10. If you update files later, use the project's new deployment / upload option to upload the updated files.

IF YOU SEE GIT-BASED DEPLOYMENT INSTEAD
You can create a GitHub repository, upload these files to its root, and connect the repository to Cloudflare Pages. For a simple first launch, direct upload is easier when available.

UPDATE YOUR URLS
After deployment, replace https://YOUR-SITE.pages.dev in index.html, about.html, privacy.html, contact.html, robots.txt and sitemap.xml with the exact URL Cloudflare assigned. Redeploy afterward.
Canonical URL and sitemap entries should use the final public URL.

IMPORTANT LIMITATIONS
- This is a static front-end project; no database, login, server-side features or message-submission form.
- Heights and names are processed in the browser. Standard hosting logs may still exist.
- The silhouette is a simplified illustration, not an exact anatomical model.
- Height inputs are limited to 50–250 cm for this starter version.
